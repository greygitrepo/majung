# Play 스토어 등록정보 (한국어, ko-KR)

> 작성 2026-11-06. 기준: Play 고객센터 answer/9866151(2026-11-06 확인), `docs/policy/play-store.md` 5절(과장·정부 표방 금지).
> 글자 수는 `python3 -I tools/check_listing.py`로 확인한다. 앱 기능·데이터가 바뀌면 같이 고친다.
> 일부러 쓰지 않은 말: "모든", "실시간", "정확한", "공식", "정부", 숫자(시설 수는 데이터마다 바뀜), 이모지.

## 앱 이름 (30자 이내)

```
마중 - 무료급식·쉼터 지도
```

## 간단한 설명 (80자 이내)

```
무료 급식소, 쉼터, 무료 진료소를 가까운 곳부터 찾아요. 가입 없이 바로 쓸 수 있어요.
```

## 자세한 설명 (4000자 이내)

```
마중은 밥 먹을 곳, 잘 곳, 아플 때 갈 곳을 한 지도에서 찾는 무료 앱이에요.

■ 이런 걸 할 수 있어요
- 무료 급식소, 노숙인 쉼터·시설, 무료 진료소와 보건소를 가까운 곳부터 보여 드려요.
- 전화 버튼을 누르면 바로 전화를 걸 수 있어요.
- 길찾기 버튼을 누르면 네이버지도나 카카오맵으로 이어져요.
- 자주 가는 곳은 "저장한 곳"에 모아 둘 수 있어요.
- 긴급 연락처(129 보건복지상담센터, 109 자살예방 상담전화, 112, 119)를 한 번에 누를 수 있어요. 서울과 경기는 지역 상담 번호도 함께 보여 드려요.

■ 위치를 안 켜도 돼요
- 위치를 켜면 가까운 순서로 보여 드려요.
- 위치를 켜기 싫으면 시·도와 시·군·구를 골라서 똑같이 쓸 수 있어요.

■ 인터넷이 없어도 돼요
- 마지막으로 받은 정보를 휴대폰에 저장해 둬요. 인터넷이 끊겨도 목록과 전화번호를 볼 수 있어요.
- 정보가 바뀌었을 때만 새로 받아서 데이터를 아껴요.

■ 보기 쉽게 만들었어요
- 큰 글자, 큰 버튼, 쉬운 말로 만들었어요.
- 휴대폰 글자 크기를 크게 해도 화면이 깨지지 않아요.

■ 꼭 알아 두세요
- 공공데이터를 바탕으로 만든 민간 앱이에요. 정부나 지자체가 만든 앱이 아니에요.
- 공공데이터는 틀린 곳이 있을 수 있어요. 그래서 시설마다 정보 출처와 마지막으로 확인한 날을 함께 보여 드려요.
- 운영 시간이 확인되지 않은 곳은 "가기 전에 전화로 확인"이라고 알려 드려요. 가기 전에 꼭 전화해 보세요.
- 정보가 틀렸으면 앱 안의 "정보가 틀렸어요" 버튼으로 알려 주세요.

■ 개인정보
- 회원가입이 없어요. 이름, 전화번호를 받지 않아요.
- 광고가 없고, 사용 기록을 모으는 분석 도구를 쓰지 않아요.
- 내 위치(좌표)는 가까운 순서를 계산할 때 휴대폰 안에서만 쓰고 밖으로 보내지 않아요.
- 다만 지도를 볼 때는 지도 그림을 받으려고, 보고 있는 동네가 지도 서버(OpenStreetMap)에 전해져요.

■ 데이터 출처
공공데이터포털 전국무료급식소표준데이터, 한국사회보장정보원 사회복지시설정보, 건강보험심사평가원 전국 병의원 현황, 지자체 노숙인시설 현황 등. 지도는 © OpenStreetMap 기여자.

문의: majungdev@gmail.com
```
