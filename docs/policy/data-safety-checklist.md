# Play 데이터 보안 양식 답안

> 작성 2026-11-06. 앱 버전 0.1.1 (2) 기준. **권한·SDK·외부 통신을 바꾸면 이 문서, 개인정보처리방침(`docs/privacy-policy.md`), Play Console 답을 함께 고친다.**

## 근거 (2026-11-06 확인)

1. Play 고객센터 "데이터 보안 섹션에 정보 제공" — https://support.google.com/googleplay/android-developer/answer/10787469
   - 수집 = "앱에서 사용자 기기 밖으로 데이터를 전송하는 것". 라이브러리·SDK가 보내는 것도 포함.
   - 기기 안에서만 처리하고 밖으로 보내지 않으면 공개하지 않아도 된다.
   - 대략적 위치 = 3㎢ 이상 범위, 정밀 위치 = 3㎢ 미만. IP로 위치를 판단하면 그것도 위치로 선언.
   - 웹뷰에서 사용자가 열린 웹을 돌아다니며 생기는 수집은 선언하지 않아도 된다.
   - 사용자와 다시 연결할 수 있는 가명 데이터는 공개해야 한다.
   - 지도 타일 요청을 직접 다룬 문장은 **없다**.
2. Google Maps Platform "Google Play 데이터 공개 요건 준비"(Maps SDK for Android) — https://developers.google.com/maps/documentation/android-sdk/play-data-disclosure
   - 지도 SDK가 스스로 선언하라고 안내하는 것은 요청 메타데이터, 오류 기록, IP 주소, SDK 식별자, 지도 조작(이동·확대) 이벤트다.
   - **보고 있는 지도 영역을 위치로 선언하라는 안내는 없다.** 다만 이 SDK는 Google에 데이터를 보내고, 우리 앱은 그런 SDK를 쓰지 않는다는 점에서 상황이 다르다.

## 앱이 기기 밖으로 보내는 것 (코드 기준)

| 받는 곳 | 언제 | 보내는 것 | 사용자 좌표 |
|---|---|---|---|
| GitHub Pages (`greygitrepo.github.io`) | 앱을 열거나 다시 볼 때, 당겨서 새로고침 | 고정 주소 요청, `If-None-Match`, IP·User-Agent(일반 접속 기록) | 없음 (테스트: "요청에 위치 정보를 담지 않는다") |
| OSM 타일 서버 (`tile.openstreetmap.org`) | 지도 화면을 볼 때 | 보고 있는 영역의 타일 번호(z/x/y), IP, User-Agent(`kr.or.majung.app`) | 좌표는 안 보냄. 하지만 **GPS 기준이면 지도가 내 위치와 가까운 3곳이 보이게 맞춰지므로(최대 16배율) 내 위치 근처 타일을 요청한다** |
| 전화·지도·메일 앱 (기기 안 다른 앱) | 사용자가 버튼을 누를 때 | 시설 전화번호, 시설 위치·이름, 신고 메일 내용 | 없음 (출발지 안 보냄) |

없는 것: 계정, 광고 SDK, 분석 SDK, 크래시 리포트 SDK, 광고 ID, 기기 ID, 백그라운드 위치, 클라우드 백업(decisions #19).

## 답안

### 공통 (어느 안이든 같음)

| 질문 | 답 | 이유 |
|---|---|---|
| 개인정보처리방침 URL | `https://greygitrepo.github.io/majung/privacy.html` | |
| 계정 만들기 | 앱에서 계정을 만들 수 없음 | 회원가입 없음 |
| 오류 신고 메일 | 선언 안 함 | 앱은 메일 앱을 열기만 하고, 보내는 것은 사용자가 메일 앱에서 직접 한다. 앱이 기기 밖으로 보내는 것이 아니다 |
| GitHub Pages 접속 기록(IP) | 선언 안 함 | 사용자 데이터를 담지 않고, IP로 위치를 판단하지 않으며 운영자가 로그를 받지도 않는다 |

### 지도 타일 — **B. 대략적 위치 수집으로 선언** (2026-11-06 결정, decisions #22)

덜 선언하면 정책 위반이지만 더 선언하는 것은 위반이 아니다. GPS 기준일 때 타일 영역과 IP를 합치면 사용자가 있는 동네를 다시 알아낼 수 있다("다시 연결할 수 있는 가명 데이터는 공개"). 개인정보처리방침 4항에도 이미 "보고 있는 지도 영역"을 적었다.

검토했던 다른 안(A. 수집 없음): 좌표를 보내지 않고 Google 지도 SDK 안내도 보는 영역을 위치로 치지 않는다는 판단. 덜 선언했다고 지적받을 위험 때문에 택하지 않음.

## Play Console 입력 순서 (B안)

1. **데이터 수집 및 보안**
   - 앱에서 필수 사용자 데이터 유형을 수집하거나 공유하나요? → **예**
   - 수집하는 모든 사용자 데이터가 전송 중에 암호화되나요? → **예** (GitHub Pages·OSM 모두 HTTPS)
   - 사용자가 계정을 만들 수 있나요? → **앱에서 계정을 만들 수 없음** (선택지에 따라 "사용자 이름과 비밀번호 등… 해당 없음")
   - 사용자가 데이터 삭제를 요청할 수 있는 방법을 제공하나요? → **아니요** (운영자가 받거나 저장하는 데이터가 없다. 타일 서버 기록은 OSM 재단이 관리)
2. **데이터 유형** → **위치 → 대략적인 위치**만 체크. 나머지 모두 체크 안 함
3. **대략적인 위치 — 사용 및 처리**
   - 수집 → **예** / 공유 → **아니요** (앱이 받아서 넘기는 것이 아니라, 사용자가 지도를 볼 때 지도 그림을 받는 요청)
   - 일시적으로 처리되나요? → **아니요** (타일 서버가 접속 기록을 남길 수 있음)
   - 필수인가요, 선택인가요? → **사용자가 선택 가능** (지도를 안 보거나 지역을 골라 쓰면 됨)
   - 수집 목적 → **앱 기능**만
4. 미리보기에서 "위치 정보 수집 / 제3자와 공유 없음 / 전송 중 데이터 암호화"로 나오는지 확인
