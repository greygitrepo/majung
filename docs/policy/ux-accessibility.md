# UX·접근성 정책

## 1. 핵심 흐름

앱을 열면 바로:

1. **카테고리 큰 버튼** — 밥 / 잠자리 / 씻기·빨래 / 진료 / 식료품
2. **가까운 순 목록** — 지금 열린 곳 먼저, 거리, 다음 운영 시간
3. **상세** — 큰 전화 버튼, 길찾기 버튼, 운영 시간, 이용 대상·조건, 마지막 확인일

- 첫 실행 온보딩·튜토리얼·스플래시 광고를 두지 않는다. 바로 쓸 수 있어야 한다.
- 지도와 목록 둘 다 제공하되 **목록이 기본**이다(작은 화면, 시력 약한 사용자에게 목록이 더 쉽다).
- 긴급 연락처(1600-9582 노숙인 위기대응콜, 120, 112, 119)는 모든 화면에서 한 번에 닿는다.
- 한파·폭염 시기에는 쉼터·응급잠자리를 상단에 보여줄 수 있게 구조를 열어둔다.

## 2. 문구

- 쉬운 한국어. 짧은 문장. 행정 용어는 풀어 쓴다("노숙인 일시보호시설" → "오늘 밤 잘 수 있는 곳" + 괄호로 정식 명칭).
- 사용자를 낙인찍는 표현을 쓰지 않는다("부랑인", "불우이웃" 등). 대상 표기는 원문이 그렇더라도 "누구나", "65세 이상", "노숙 중인 분" 같은 중립 표현으로.
- 불확실한 정보는 단정하지 않는다: "운영 중" 대신 "운영 시간입니다 (마지막 확인 10월 12일)".
- 오류 메시지는 다음 행동을 알려준다: "인터넷이 안 돼요. 저장된 정보로 보여드릴게요."
- 다국어(영어, 중국어 간체, 베트남어 등)는 나중에 추가할 수 있게 **처음부터 문자열을 리소스로 분리**한다. 하드코딩 금지.

## 3. 접근성 (필수)

- 터치 영역 최소 **48×48dp**. 주요 버튼(전화, 길찾기)은 더 크게.
- 시스템 글자 크기 **200%** 에서 잘림·겹침 없이 동작.
- 텍스트 대비 **4.5:1 이상**(WCAG AA). 색만으로 정보를 전달하지 않는다(열림/닫힘은 색 + 글자).
- TalkBack으로 모든 버튼과 정보를 읽을 수 있게 의미 있는 라벨을 단다.
- 다크 모드 지원(배터리 절약, 야간 사용).

## 4. 성능·환경

- 저사양 기기(RAM 2GB급)에서 앱 시작 2초 이내 목표.
- 데이터 업데이트는 Wi-Fi 우선 옵션을 두고, 증분·압축으로 작게.
- 배터리: 위치는 화면을 열 때 한 번 받는다. 지속 추적 금지.
- 오프라인: 목록, 상세, 전화번호, 긴급 연락처는 네트워크 없이 동작. 지도 타일이 없으면 목록으로 자연스럽게 대체.
